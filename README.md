# 感情ベースのAIタロット相談チャットボット 

> Claude API・ChatGPT の助けを借りてコードを作成しており、**アーキテクチャ設計とフローの理解に重点を置いた学習プロジェクト**です。

---

##  プロジェクト紹介

ユーザーの感情を入力として受け取り、タロットカードを引いて過去の感情記録を分析し、パターンを提供する LLM ベースの Web チャットボットです。

普段好きなタロットをテーマにすれば楽しみながら学べると考えてスタートしました。単に API を呼び出すだけでなく、LLM がどのように動作し、Tool Use のフローがどう構成されるかを直接理解することを目標としました。

---

##  制作目的

- LLM の仕組みと動作フローを深く理解する
- Tool Use の呼び出しパターンを実際に体験する
- 好きなテーマで自主学習を行う

##  主要機能

- 感情入力 → タロットカード自動抽出
- 感情記録の保存（MySQL）
- 過去の感情パターン分析・表示
- System Prompt による役割制限

---

##  Tool Use フロー

```
① tools リストを LLM に渡す
        ↓
② LLM が自ら判断 → tool 使用 or 直接回答
        ↓
③ tool_use ブロック受信時、for ループで順次処理（マルチ tool 対応）
        ↓
④ 実行結果を LLM に戻す → 最終応答を生成
```

`save_record` と `draw_tarot_card` が同時に呼び出されるケースに対応するため、for ループで tool_use ブロックを順次処理するよう実装しました。

---

##  理解できたこと

**System Prompt と Context の違い**
System Prompt は役割定義、Context は会話履歴であることを、実装を通じて直接理解しました。

**AI Agent の接続フロー**
Tool を定義し、LLM の判断に基づいて実行する Agent パターンを自ら実装することで、これまで感覚的に使っていた AI Agent を理論として理解できました。また、今後プロンプトを書く際は明確かつ丁寧に書かなければならないと実感しました。

**マルチ Tool の処理**
tool が同時に2つ返ってきた場合、for ループで順次処理する方法を自分で考案して実装しました。
